# ARCTIS Streamlit Prototype

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

This is a UI/UX prototype. AI/ML outputs are simulated; the architecture is ready for later model integration.

## Prototype behavior
- Home dashboard with clickable module cards.
- Sidebar navigation.
- Page-by-page tutorial using thought-bubble style guidance.
- Cargo search/filter and clickable shipment details.
- Personnel, Assets, Inventory, Communications, Emergency and AI Advisor pages.
- Restart Tutorial button.
